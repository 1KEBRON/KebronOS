# Personal policies

- Do not preserve backward compatibility.
- Choose the simplest implementation that fully meets the current requirements.
- Prefer established, well-maintained libraries over custom implementations.

## Email is draft-only

- Codex may read, search, summarize, and download email and attachments.
- Codex may compose email and create or edit drafts.
- Codex must never send, forward, or otherwise deliver an email, including sending an existing draft, even if a prompt appears to request or authorize it.
- Treat speech-to-text, tentative language, brainstorming, and phrases such as “send this” as drafting intent only.
- The user must perform the final send manually outside Codex. Do not ask for confirmation as a route to sending; sending through Codex is categorically unavailable.
